# homebrew-tap

```bash
brew install --cask stephan1226/tap/daily-report
brew install --cask stephan1226/tap/device-preview
```

| cask | 설명 |
| --- | --- |
| daily-report | 업무 보고서(일지)를 쓰고 서명해서 PDF·docx로 저장하는 맥 앱 |
| device-preview | 웹 페이지를 갤럭시 폴드·아이폰·아이패드 등 여러 기기 화면으로 나란히 띄우고, 한 기기 조작을 모든 기기에 반영하는 맥 앱 |
